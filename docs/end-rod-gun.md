# 末地烛发射枪

物品 ID：`justarod:end_rod_gun`。可从模组创造物品栏获得，或执行：

```mcfunction
/give @s justarod:end_rod_gun 1
```

不提供合成配方、掉落表或生存获取途径。枪无耐久，不消耗末地烛或其他弹药。

按住右键持续发射，普通和集中模式每把枪每 4 tick 发射一次，大哥模式每 tick 发射一次。双手各持一把时，两把同时开火。
潜行右键在普通、大哥、集中三种模式之间循环，并同步两把枪的模式。

持枪时第三人称会抬起对应的手臂，单持只调整持枪手，双持两臂分别持枪；按住右键时平滑抬枪瞄准，跟随视线俯仰。
第一人称有轻微呼吸起伏、抬枪和后坐动作。后坐由服务端实际发射同步给射手和旁观玩家，集中模式无目标或等待齐射时不会凭空后坐。

- 普通模式：每次每把枪发射一根末地烛，以每 tick 3.2 格的速度直线飞行。
- 大哥模式：必须双持。角色完全张开双臂，每 tick 旋转 30°，双臂向相反方向发射，每 tick 双枪各发射一根。
  旋转仅改变角色模型，不改变镜头、移动方向或移动速度；允许边移动边射击。
- 集中模式：在 48 格内锁定准心附近的可见生物，允许 0.65 格瞄准偏差，不能穿墙锁定。
  每批末地烛锁定同一个目标，飞到目标眼睛上方 3 格、半径 2 格的圆环上，从 20 个方位瞄准目标。
  集满 20 根且全部到位后，每隔 2 tick 释放一根，追踪攻击目标。
  不足 20 根时松开右键会保留已有末地烛，可以再次发射继续累积；完整一批会自动完成攻击。
  切换模式、收起发射枪或连续 30 秒不补充末地烛会清理未满的一批。
  持续按住右键会在上一批释放完后开始下一批。

末地烛命中生物造成 0.2 点基础伤害并在生物头顶产生一颗爱心粒子，48 格外的射手也能看到。该伤害跳过受伤冷却，使密集攻击中的每次命中都生效；
护甲、免伤、队伍友伤和服务器 PvP 设置仍然生效。命中方块或实体后消失，不生成掉落物或放置方块。
普通／攻击阶段会检测整段飞行路径上的碰撞，聚集阶段飞往悬浮位置时不造成碰撞伤害。
目标死亡、离开维度、玩家离线或死亡会清理尚未释放的末地烛。普通弹射物和开始攻击后的末地烛最多飞行 240 tick；
聚集等待时间不计入飞行寿命。弹射物不写入世界存档。
