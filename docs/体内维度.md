# 玩家体内维度（第一版）

适用于当前 Minecraft 26.1.2 的 Fabric / NeoForge 构建。维度 ID 为 `justarod:inside_body`。

## 使用

- 潜行并空手右键其他玩家，选择口腔、阴道或肛门进入。阴道选项由服务端按宿主现有的女性状态校验。
- 手持「体内穿入器」右键其他玩家或粉白蛔虫娘，可从任意位置进入。该道具可制作，重复使用。
- 粉白蛔虫娘（`justarod:ascaris`）同样拥有独立的体内维度区域，空间按**真实雌性似蚓蛔线虫（*Ascaris lumbricoides*）解剖结构**构建，并全部使用**自定义生物组织方块**（生存模式可挖掘带走）：
  - 外层为无体节的圆筒体壁（`ascaris_cuticle` 角质层 + `ascaris_muscle` 纵肌束 + `ascaris_nerve_cord` 背/腹神经索 + `ascaris_excretory_membrane` 左右侧线与前腹 H 形排泄管横桥），包裹带浅层体腔液与 `ascaris_pseudocoelom_membrane` 透膜的**假体腔**；
  - 四条入口落点分别对应真实器官：**口腔**落在品字形三唇与 Y 形三辐射肌肉咽（前方穿过纯神经组织构成的围咽神经环与半透 `ascaris_intestinal_membrane` 笔直扁平肠道，内有 `ascaris_chyme_block` 甜味食糜团）；**阴道**落在前 1/3 腹侧阴门与阴道（后方分叉为由 `ascaris_uterine_wall` 构成、满载 `ascaris_egg_sac` 蛔虫卵囊块的左右双管子宫，向后衔接受精囊/输卵管与 `ascaris_ovary_tissue` 盘绕丝状卵巢）；**肛门**落在尾端直肠；**体内穿入器**直接落入中央假体腔，消化道与假体腔之间通过 `ascaris_mucosa_stairs` 黏膜阶梯互通；
  - 体内不播放铃声，也不放置铃铛，仅保留柔和的液体/心跳自然生物氛围；
  - **体内器官实时玩法与硬核生理循环**：
    - 左上角内置**体内生理监护面板**（并实时联动边缘微晕与镜头柔和微律动），动态呈现**静水骨骼液压（kPa）**、**厌氧糖原储备**、**代谢废物负荷**、**核心体温（°C）**、活跃食糜团/直肠充盈、卵巢→双管子宫周期、体壁完整度与双药药理状态；
    - **活体消化流水线（咽部抽吸 → 移动食糜团 → 微绒毛吸收 → 直肠排空）**：
      - 外界或咽部投喂甜食时，**Y 形三辐射肌肉咽**触发负压抽吸泵（将未潜行的咽部访客向肠道内吸入）并生成一枚携带风味的**流动食糜团**；空手轻挠咽壁也会经神经反射弧触发外界打嗝/吞咽反应；
      - 肠道产生真正从咽部扫向尾端直肠（`x = -36 → +41`）的**物理滚动蠕动波**（空腹低糖原时转为强力饥饿移行复合波 MMC 并伴随肠鸣音，按住潜行可抓紧肠壁抵抗），推动食糜团前进；
      - 食糜团流经笔直肠道时，按局部完好的 `ascaris_microvilli` 肠绒毛数量真实吸收营养（破坏肠绒毛会降低吸收率！空手右键肠绒毛可探查完整度并激发吸收加速），吸收的能量转化为宿主糖原、饱食与生命恢复，残余物汇入直肠并在充盈满载后触发**排空反射波**；
    - **静水骨骼液压、体壁破口与体腔免疫细胞自主修复**：
      - 外界粉白蛔虫娘奔跑、跳跃、钻缝、受击或缠绕时，体内的背腹神经索会发射**级联传导的生物电脉冲波**，同步拉升静水压、消耗糖原并带来轻柔微律动；
      - 破坏体壁/器官会留下**组织破口**导致静水压渗漏与炎症高热；假体腔中的 5 只**粉白体腔小细胞（`justarod:ascaris_coelomocyte`）**除平时陪伴与警戒外，还会主动飞往破口处消耗少量糖原凝集修补微小破损（绝不覆盖玩家摆放的箱子与装饰），代谢废物过高时也会聚向排泄桥协助排毒；
    - **H 形排泄管稳态与双药硬核药理（宝塔糖 vs 阿苯达唑）**：
      - H 形排泄管横桥的方块完好度直接决定代谢废物清除速率（挖断横桥将引发酸中毒）；右键 `ascaris_excretory_membrane` 除净化访客自身外，更可疏通宿主排泄孔、清代谢毒并大幅缩短药毒；
      - **从内部向咽部/神经环使用宝塔糖或阿苯达唑**（或钻入已被驱虫药熏倒的粉白蛔虫娘体内），会触发真实药理分化：
        - **宝塔糖（枸橼酸哌嗪）**：阻断神经肌肉接头 → 背腹神经传导完全熄灭、静水压暴跌、肠道蠕动停摆、**全部出口括约肌弛缓松开**（病娇高执念下亦可借药理麻痹突破出口滑出！）；
        - **阿苯达唑**：抑制微管聚合 → 阻断 90% 肠绒毛葡萄糖摄取、糖原断崖枯竭、食糜萎缩并伴随炎症高热；访客可通过在 H 形排泄管反复冲洗排毒 + 咽部灌注甜食，直接从内部**抢救垂危的粉白蛔虫娘**；
    - **完整双管生殖周期（卵巢 → 输卵管 → 双管子宫 → 阴道宫缩产卵）**：
      - 盘绕丝状卵巢消耗糖原推进卵母细胞成熟度（空手右键 `ascaris_ovary_tissue` 可温热刺激加速排卵并引发外界害羞反射），成熟后经左右输卵管与受精囊输送至双管子宫，按解剖流向**从后段向阴门前段**依次生长 `ascaris_egg_sac`；
      - 双子宫满载后触发**产道规律宫缩波**，向腹侧阴门推进并排出温热的「蛔虫卵胶囊」；三大天然孔道（**口腔三唇、前 1/3 腹侧阴门、尾端肛门**）均支持空手右键自然滑出；
    - **围咽神经环 · 神经视窗与体内遥控**：
      - 空手右键轻抚可大幅降低病娇执念（-20%）、平复体腔细胞并回血；
      - **潜行 + 空手右键**开启跨维度**「神经视窗」**，透过粉白蛔虫娘的双眼实时观察外界并遥控她（鼠标环顾四周、`WASD` 挪步、`空格` 轻跳、`R` 坐下/起身、`G` 钻 1 格缝隐藏、`X` 或 `Shift` 断开无缝返回围咽神经环）；
      - 手持「粉白虫蜕」右键围咽神经环可触发**器官温和自愈**（仅修补被挖空的原始解剖空气缺口，同步清除破口漏压，绝不触碰玩家建筑）；
    - **体温暖窝小睡与「暖腹余温」**：在中央假体腔的 `ascaris_warm_cushion` 上普通右键可依偎回血/安抚执念；**潜行 + 右键**可安心入眠（直接安稳跳过主世界黑夜与风雨，完全恢复生命/饱食、缓解高热与代谢负荷、大幅降低执念）；正常离开她的身体或在其暖窝小睡后还会获得「**暖腹余温（`justarod:warm_belly`）**」有益状态；
    - **生存退出规则与病娇逃生**：在粉白蛔虫娘体内的**生存/冒险模式**下禁用按 `J` 直接瞬移退出，需步行前往**口腔三唇、前 1/3 腹侧阴门或尾端肛门**空手右键自然滑出；病娇执念 `>= 50%` 时出口括约肌紧闭，除温柔安抚至 `50%` 以下外，亦可利用**宝塔糖（哌嗪麻痹）**令括约肌弛缓松开逃出（离开后体内安抚或挑衅结果均完整同步回外界本体）。
    - **玩家宿主体内实时生理联动**：进入其他玩家体内时，ActionBar 与环境粒子/音效亦会实时反映宿主当前的心跳、孕期胎动、月经周期、宫寒寒雾与肠道/膀胱压力；
    - 另提供调试命令 `/ascaris physiology <status|drug|bolus|ovulate|waste|glycogen>` 方便直接观察与测试各项生理状态。
  - **体内生机与温馨陪伴**：
    - 神经索脉冲、排泄管体液流动、假体腔液水波、卵囊呼吸微光、肠壁上皮与 `ascaris_microvilli` 柔粉肠绒毛均配有动态呼吸贴图，各器官持续飘散专属微粒；
    - 假体腔中自由漂浮着 5 只半透发光的**粉白体腔小细胞（`justarod:ascaris_coelomocyte`）**：平时绕着玩家轻盈飘游陪伴、空手轻抚回血、喂甜食滋养玩家与宿主；乱拆体内组织或攻击它们时会泛红进入免疫警戒轻推护体，安抚围咽神经环或依偎软垫后立刻恢复粉白；
    - 滞留期间她还会感应外界昼夜、雨雪与你的伤势隔着肚皮轻声搭话；
  - **带回主世界的自定义方块功能**：`假体腔液透膜` 减免 80% 摔落伤害并带水床轻弹缓冲，`柔暖体腔软垫` 减免 85% 摔落伤害且右键依偎回血/清疲劳与宫寒，`柔粉肠绒毛` 支持地面丛生与顶壁垂挂，`甜味食糜团` 可分 4 口食用（含 3 种风味），`蛔虫神经索` 踩踏或右键输出 16 tick 生物电红石脉冲（强度 10），`蛔虫排泄管膜` 右键排毒（20 秒冷却），`蛔虫纵肌束` 减半摔落伤害，`蛔虫卵囊块` 可当柔和荧光灯或右键剥取虫卵胶囊；
  - 手持「体内穿入器」右键任意粉白蛔虫娘即可直接穿入；
  - 缩小体型后（`<= 0.65x`）潜行空手右键自己的粉白蛔虫娘，或直接潜行空手右键非自己驯服的粉白蛔虫娘，可选择口腔、阴道或肛门进入（正常体型潜行空手右键自己的粉白蛔虫娘仍保留原姿态切换）；
  - 也可通过 `/ascaris enter [mouth|vagina|anus|anywhere]` 快速进入附近粉白蛔虫娘的体内；
  - 外界给她喂宝塔糖或阿苯达唑时会把体内访客直接排出来；粉白蛔虫娘通过小金铃收放至宿主玩家体内前后保留同一体内区域；死亡时自动退休旧区域并安全送出在线访客。
- 玩家宿主体内（或粉白蛔虫娘体内的创造/旁观模式）仍可按 `J` 或执行 `/body exit` 返回原位置；原位置不安全时返回主世界出生点。
- 管理员可用 `/body reset <玩家或粉白蛔虫娘实体>` 手动重置已有区域。

交互、目标距离（5 格内）、道具和入口条件均由服务端校验。玩家不能进入自己体内。

## 区域及重置

每名宿主按 UUID 分配一个 512×256 格的水平区域。区域中心落在间距 1024 格的网格上，相邻区域之间至少留出 512 格（X 方向）或 768 格（Z 方向）。分配编号持久化在主世界的 `SavedData` 中；旧编号永不复用，达到坐标安全范围的容量上限时拒绝新分配。

首次进入时在区域中心生成带四个落点的安全房间。访客越出区域时会被带回本区中心；跨维度移动或宿主离线时访客记录会被清理或送出。

宿主死亡时自动分配新区，并把在线访客送出。旧区域不再使用，但旧区块文件不会自动删除；长期频繁重置会增加存档占用。

## 配置

`config/justarod.json` 中的 `inside_body.enabled` 默认是 `true`。设为 `false` 后，维度定义仍随模组注册，服务端会拒绝进入请求、将现有访客送出，并取消该维度的世界 tick。建议修改后重启服务器，使所有客户端与服务端状态一致。

## 验证

Fabric GameTest 校验维度类型和维度 JSON 可解析、区域编号与坐标唯一，以及重置和访客数据的磁盘存档往返。GameTest 使用固定的原版三维度世界预设；客户端游戏测试另建普通游戏世界，验证了维度实际加载、通过网络请求进入、使用特殊道具进入、退出、重置、关闭配置后拒绝进入，以及关闭后的实体 tick 停止。
