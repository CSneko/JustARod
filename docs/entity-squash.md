# 全体实体同步压缩与旋转

客户端配置界面中的「整活 → 全体实体同步压缩与旋转」可开启此效果，默认关闭。
配置文件为游戏目录下的 `config/justarod.json`，使用扁平键：

```json
{
  "fun.entity_squash.enabled": false,
  "fun.entity_squash.compression_ratio": 0.5,
  "fun.entity_squash.bpm": 120.0
}
```

- `enabled`：是否开启。
- `compression_ratio`：最大压缩时保留的高度比例，范围 `0.1~1`，默认 `0.5`。横向（X/Z）按倒数放大，因此默认半高、两倍宽；设为 `1` 不压缩，但仍会旋转。
- `bpm`：以四分音符计的 BPM，范围 `10~600`，默认 `120`。

节奏为 4/2 拍：每小节四个二分音符，第 1、3 拍达到最大压缩，第 2、4 拍恢复原状，之间平滑过渡。
每次压缩/恢复之间相隔 `120 / BPM` 秒；120 BPM 时每秒切换一次，四秒一小节。
所有实体共用高精度渲染帧时钟，开启时按世界游戏时间对齐节拍，之后按每帧实际经过的时间连续推进。
每帧只计算一次缩放和旋转，新生成的实体立即跟上其他实体；单人暂停或冻结游戏 tick 时动画暂停，恢复时不会突然快进。
较长时间运行的世界也保留帧内小数精度，服务器校时不会拉动动画，调整 BPM 只改变后续速度而不跳相位。

开启时，所有实体还会同步绕自身的竖直轴匀速旋转，每个 4/2 拍小节转一圈。
默认 120 BPM 时每秒转 90°、四秒转一圈；改变 BPM 会同时改变压缩和旋转速度。
旋转与压缩共用同一帧的节拍相位，保持实体位置固定；关闭开关后同时恢复原尺寸和原朝向。

效果在统一的实体渲染入口应用，覆盖玩家、生物、掉落物、载具等；史莱姆体内的实体随外壳一起压缩和旋转，不会重复叠加。
该选项仅控制本地视觉表现，不改变碰撞箱、实体属性或服务器玩法；各客户端自行开启。
新配置键在模组启动时自动补全，配置界面修改即时生效，手动修改文件后需重启游戏。
数字输入会按整数/小数类型保存，点击「应用」后写入文件；折叠分组、调整窗口或重新打开界面会显示当前值。
输入不完整或不是有效数字时会显示红字，保留上一次有效数值；旧版界面保存的数字字符串会在启动时自动转换为数字。

验证命令：`./gradlew :common:verifyMixins :fabric:shadowJar :neoforge:shadowJar`；
客户端回归：`./gradlew -PslimeClientTests :fabric:runClientGameTest`，包含高帧率、长时间运行世界、校时、BPM 调整及暂停恢复的连续性检查，以及玩家/生物/掉落物的真实渲染矩阵检查。
