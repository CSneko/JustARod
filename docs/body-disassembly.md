# 身体拆卸：视频拍摄与玩法

适用当前 Minecraft 26.1.2 构建。Fabric 与 NeoForge 共用实现。

## 立即开始

- **H**：打开身体拆卸菜单，拆下、装回、放下部件，安排挖矿或切换视角。
- **Y**：直接摘下脑袋。优先放进空主手，主手拿镐子时放进空副手；双手都占用时进入背包。按键可在设置中修改。
- 七个部位分别是头、左右手、左右腿、左右眼。部件继承本人的皮肤与细手臂模型，带皮肤外层。拆下的部位从玩家模型和普通人形盔甲模型隐藏，对应手上的物品也隐藏。
- 像普通物品一样丢给朋友，或放进容器。部件不会因交接改变主人。
- 手持部件右键方块放置；潜行使用可装回本人身体。也可拿部件右键其主人装回。
- 世界中的部件：潜行空手右键捡起；主人潜行攻击直接装回。菜单“装回”使用背包里的部件，因此没有双手时也能操作。

## 各部位功能

**头**：放在方块上会看向附近玩家、眨眼；主人空手敲一下说“来，帮咱拿一下脑袋”。文字气泡出现时脑袋轻晃。空手右键或菜单“观察”进入头部视角。角色对白留给后期配音。

**手**：先放下，再右键交给它一把带工具属性的工具。自己对准 8 格内方块，在 H 菜单选择该手的“挖矿”，或使用 `/jarbody mine left_arm`。它会跳向目标，开采所指表面的 3×3 方块；要求主人在目标 16 格内。硬度、掉落和工具耐久使用原版服务端挖掘逻辑，方块实体和不可破坏方块跳过；附近掉落送进主人背包，满了就留在地上。空手右键取回工具，召回会停止工作。

**腿**：放下后右键交给它一叠物品，它会蹦向主人送货，背包满时把货物丢在主人身边。拆掉一条腿会减速、身体轻晃；拆掉两条腿会以低矮碰撞箱爬行并禁止地面跳跃。飞行、骑乘和睡眠保留原有姿态。

**眼睛**：放下后空手右键借用其镜头；菜单“双视角”同时看身体和外置眼睛的画面。少一只眼时第一人称边缘变暗；两只都不在时第一人称视野遮挡，可用 H 菜单借用外置视角。

远程观察要求部件在同一维度、64 格内且客户端已加载。完整远程视角时身体留在原处，方向可以用鼠标调整。潜行、X 或 H 菜单“返回身体”退出；受伤、超距或部件装回身体也会退出。此版本不强制加载远处区块。

### 交接、背包与安装到别人身上

- 别人把脑袋或眼睛拿在主手或副手时，镜头跟着那只手移动，身体仍留在原地。观察目标绑定部件身份，交接不会中断。
- 对方把部件收进普通背包后，自动打开“背包里的视角”，可以看到真实物品、数量、耐久和悬停说明，并随背包变化刷新。这是只读画面，不能从中搬动物品；只有部件主人收到这份背包画面。
- 拿着**自己的眼睛右键另一名玩家**，把它安装到对方胸前，自动开启双画面：左边是自己的视角，右边是那只眼睛跟随对方身体和朝向的画面。安装不会夺走对方原有的眼睛；每个目标可以各装一只左眼、一只右眼。
- 双画面时仍可以控制自己的身体。每个画面交替刷新，为游戏帧率的一半，保持两个实时视角而不重复运行世界逻辑。
- 主人潜行空手右键目标可以取回自己的眼睛；被安装者可用 H 菜单“取下外来眼睛”或 `/jarbody unmount` 自行取下。眼睛回到手里或背包后，正在观察的视角随之切换。
- `/jarbody view left_eye` 可以改用完整远程画面；`/jarbody dual left_eye` 恢复双画面。安装关系随目标玩家存档保存，重进游戏后可再次观察。

背包画面目前指玩家的普通物品栏；不展开箱子、潜影盒或第三方背包物品内部的嵌套空间。

## 部件脾气

默认开启，H 菜单可切换。连续工作约 60 秒开始抱怨、90 秒停工，之后继续闹脾气会跑路；闲置时积累更慢。部件出逃在主人附近活动，方便追逐。主人普通攻击出逃或罢工部件可安抚，之后可以捡起或装回。

“召回”只召回**本维度已加载的部件实体**，清除工作和跑路状态。背包、箱子或未加载区块中的部件仍保留原位置。

身体缺失状态、部件身份、皮肤和装备随存档保存；重新加载不自动继续挖矿或跑路。死亡后身体恢复，旧身份不能再次装回。部件被环境破坏时掉落本体与装备，可捡回。

## 拍摄指令

这些指令只作用于执行者自己的身体，不需要 OP。

| 指令 | 效果 |
| --- | --- |
| `/jarbody detach head` | 摘头；其他部位见下方 |
| `/jarbody place head` | 把背包里的头放到准星位置，4 格内 |
| `/jarbody attach head` | 从背包装回头 |
| `/jarbody view head` | 借用放下的头的镜头 |
| `/jarbody view left_eye` | 借用左眼镜头，支持放置、手持、背包和已安装状态 |
| `/jarbody dual left_eye` | 同时显示自身和左眼的视角 |
| `/jarbody unmount` | 取下安装在自己身上的外来眼睛 |
| `/jarbody exit` | 返回身体视角 |
| `/jarbody mine left_arm` | 左手开采准星所指的 3×3 表面 |
| `/jarbody strike left_arm` | 左手停工并抱怨 |
| `/jarbody run left_leg` | 左腿开始逃跑 |
| `/jarbody run all` | 拆下所有部位、部署背包中的部件，并让已加载的部件集体出逃 |
| `/jarbody say 来，帮咱拿一下脑袋。` | 已放置的头显示指定台词，约 5 秒 |
| `/jarbody recall` | 停工，召回本维度已加载的实体部件 |
| `/jarbody reset` | 紧急完整复位，退出视角并恢复全部身体 |
| `/jarbody random off` | 禁止自然闹脾气，适合重拍 |
| `/jarbody random on` | 恢复自然闹脾气 |

部位 ID：`head`、`left_arm`、`right_arm`、`left_leg`、`right_leg`、`left_eye`、`right_eye`。

`reset` 会清理在线玩家背包中属于执行者的部件及已加载实体，实体携带的工具/货物在原地掉落。箱子、离线玩家和未加载区块中的旧部件不会被远程搜索；旧部件身份失效，不能再次部署或装回。工具/货物仍保留于未加载实体，待主人在线并加载后掉落。

建议开场：主手留空 → Y 摘头 → Q 丢给摄影玩家；或 H 放到桌面 → `/jarbody say 来，帮咱拿一下脑袋。`。结尾使用 `/jarbody run all`，重拍前 `/jarbody reset`。集体出逃最好在开阔地、准星对准脚边地面且背包留空位时拍摄。

## 外观范围

使用原版玩家皮肤（含外层），不会自动复制其他模组的独立猫耳装备、GeckoLib 角色、VRM 或 Figura 自定义模型。此类外观需要对应渲染器的额外适配。头的说话为字幕气泡和动作，不内置语音合成。
