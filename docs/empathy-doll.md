# 共感娃娃

共感娃娃是使用绑定玩家皮肤的 Fumo 坐姿布偶：大头、短身体、向前伸出的双腿。
帽子、衣服和四肢的皮肤外层保留，支持宽手臂和细手臂皮肤。手持物品与摆放实体共用模型。
未绑定或皮肤尚未加载时使用原版默认皮肤；皮肤下载和缓存复用原版系统。

## 获取与绑定

- 创造模式：JustARod 物品栏中的「共感娃娃」。ID：`justarod:empathy_doll`。
- 合成：第一行中间放线，第二行「羊毛、末影珍珠、羊毛」，第三行中间放羊毛。
- 手持娃娃右键玩家：绑定该玩家。
- 未绑定时潜行右键空气：绑定自己。
- 已绑定时潜行右键空气：解除绑定。
- 右键方块：摆放，朝向操作者。空手潜行右键摆好的娃娃：收回。

绑定玩家的 UUID、名字及皮肤资料存储在物品的 `minecraft:profile` 组件中，摆放、收回、存档重载都会保留。
同一目标可以绑定多个娃娃。目标需要在线、存活、处于同一维度且不是旁观者；目标没有距离限制，操作者必须能正常触及娃娃。

## 六种互动

| 操作 | 反应 | 时长 |
| --- | --- | --- |
| 空手右键 | 放松的手臂、轻缓摇摆，少量粉色粒子 | 3 秒 |
| 羽毛右键 | 明显左右抖动、手臂乱摆，落地状态下小跳一次 | 2 秒 |
| 冰／浮冰／蓝冰右键 | 收拢双臂、发抖，寒气和雪花 | 4 秒 |
| 仙人掌右键 | 短促激灵、受击反馈和粒子，造成 0.5 点生命值伤害（¼ 颗心） | 0.6 秒 |
| 空手左键 | 娃娃与目标同步压扁、横向鼓起并回弹；播放提供的挤压音效 | 0.8 秒 |
| 末地烛右键 | 短暂愣住，并获得 orgasm 效果，由效果持续在头顶产生大量爱心 | 3 秒 |

道具不消耗，也不会给娃娃造成普通攻击伤害。反应不会更改玩家碰撞箱、缩放属性或旋转角度；羽毛会产生一次真实小跳。
反应由服务端判定，目标和附近旁观者同步看到。第一人称有手部动作和可关闭的轻微视角反馈。
对同一目标的互动共用冷却，默认 1 秒，换娃娃不能绕过。连续空手左键挤压例外：每次新点击立即打断当前挤压，让娃娃和玩家同步从头播放，并重新播放挤压音效；同一 tick 的重复攻击回调只处理一次。其他互动仍遵守共用冷却。新的互动替换旧反应，不叠加。
死亡、离线、换维度时清除临时状态，反应结束后自动恢复。

## 配置

`config/justarod.json` 中新增以下键，也可在模组设置界面的「共感娃娃」分组调整：

```json
{
  "empathy_doll.enabled": true,
  "empathy_doll.cooldown_ticks": 20,
  "empathy_doll.camera_motion": true
}
```

- `enabled`：服务端控制绑定、摆放和互动。关闭后，已有娃娃仍能收回。
- `cooldown_ticks`：服务端目标共用冷却，限制 5～200 tick；连续挤压允许立即重播。
- `camera_motion`：本地第一人称轻微视角反馈；关闭后保留模型动作和粒子。

与「全体实体同步压缩与旋转」可同时使用，两者独立计算并在渲染时组合。
挤压音效源文件为用户提供的 `650957bc9f70d.mp3`，裁去前约 0.785 秒的空白和低电平段，并去掉尾部空白后转成单声道 OGG（约 0.43 秒），保存在 `assets/justarod/sounds/doll_squeeze.ogg`；音效起音与挤压开始对齐。

末地烛接触给予 60 tick 的 `justarod:orgasm` 效果，遵循原版效果合并规则。爱心由 `OrgasmEffect` 的服务端粒子广播统一产生，直接使用其他道具或命令施加该效果也会显示，娃娃不再单独叠加爱心。效果初次生效时立即爆发 40 颗爱心，随后基础等级每 2 tick 发出 20 颗（每秒约 200 颗）；提高等级会增加数量，并设有上限。爱心围绕眼睛高度和头顶产生，第一人称也能看到；使用强制显示广播，避免被「最少粒子」设置或普通 32 格粒子范围过滤。刷新已有效果时不会重复初始爆发。

## 验证

```bash
./gradlew :common:verifyMixins :fabric:shadowJar :neoforge:shadowJar
./gradlew :fabric:runGameTest
./gradlew -PslimeClientTests :fabric:runClientGameTest
```

服务端与客户端测试应分别启动，避免 Architectury 共享启动配置发生冲突。
`EmpathyDollGameTests` 覆盖绑定、摆放、存档、收回、远距离六种互动、共享冷却、失效目标、微量仙人掌伤害、orgasm 施加、独立效果的爱心网络包、连续挤压重播及死亡恢复。
`EmpathyDollClientGameTests` 覆盖真实羽毛输入与数据包、Fumo 实体和物品渲染、姿势、真实连续左键重播、压缩恢复与全体压缩兼容，并生成娃娃截图。
`OrgasmClientGameTests` 额外验证无娃娃、隐藏普通药水粒子、最少粒子设置下的实际爱心数量、第一／第三人称视锥内的可见粒子，以及 40 格外目标的广播，并生成两个视角的截图。
