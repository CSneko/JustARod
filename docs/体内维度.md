# 玩家体内维度（第一版）

适用于当前 Minecraft 26.1.2 的 Fabric / NeoForge 构建。维度 ID 为 `justarod:inside_body`。

## 使用

- 潜行并空手右键其他玩家，选择口腔、阴道或肛门进入。阴道选项由服务端按宿主现有的女性状态校验。
- 手持「体内穿入器」右键其他玩家，可从任意位置进入。该道具可制作，重复使用。
- 进入后按 `J` 或执行 `/body exit` 返回原位置；原位置不安全时返回主世界出生点。
- 管理员可用 `/body reset <玩家>` 手动重置已有区域。

交互、目标距离（5 格内）、道具和入口条件均由服务端校验。玩家不能进入自己体内。

## 区域及重置

每名宿主按 UUID 分配一个 512×256 格的水平区域。区域中心落在间距 1024 格的网格上，相邻区域之间至少留出 512 格（X 方向）或 768 格（Z 方向）。分配编号持久化在主世界的 `SavedData` 中；旧编号永不复用，达到坐标安全范围的容量上限时拒绝新分配。

首次进入时在区域中心生成带四个落点的安全房间。访客越出区域时会被带回本区中心；跨维度移动或宿主离线时访客记录会被清理或送出。

宿主死亡时自动分配新区，并把在线访客送出。旧区域不再使用，但旧区块文件不会自动删除；长期频繁重置会增加存档占用。

## 配置

`config/justarod.json` 中的 `inside_body.enabled` 默认是 `true`。设为 `false` 后，维度定义仍随模组注册，服务端会拒绝进入请求、将现有访客送出，并取消该维度的世界 tick。建议修改后重启服务器，使所有客户端与服务端状态一致。

## 验证

Fabric GameTest 校验维度类型和维度 JSON 可解析、区域编号与坐标唯一，以及重置和访客数据的磁盘存档往返。GameTest 使用固定的原版三维度世界预设；客户端游戏测试另建普通游戏世界，验证了维度实际加载、通过网络请求进入、使用特殊道具进入、退出、重置、关闭配置后拒绝进入，以及关闭后的实体 tick 停止。
