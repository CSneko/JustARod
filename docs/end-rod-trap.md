# 末地烛陷阱

方块 ID：`justarod:end_rod_trap`，方块实体 ID 同名。可从模组创造物品栏获得，或执行：

```mcfunction
/give @s justarod:end_rod_trap 1
```

合成（8 个铁锭 + 铁活板门 + 活塞）：

```
铁锭  铁活板门  铁锭
铁锭           铁锭
铁锭    活塞    铁锭
```

没装末地烛时显示朝上的发射器模型；装填和伪装都不改变碰撞箱，始终是一个完整的实心方块，
硬度和石头一样（3.5，需要镐子，否则挖掉不掉落）。

## 装填

主手拿**任意末地烛**（`justarod:giant_rod` 巨型末地烛除外）右键点击陷阱，就把这根末地烛装进去，
**创造模式也会从手上扣掉一根**——陷阱当容器用，装进去的东西在取出 / 打掉时会还给你，
如果创造模式不扣，就能靠「取出 → 装回」无限刷烛。装进去的末地烛保留自己的全部组件：
耐久、主人、速度、已使用次数等。

里面已经有一根时再装一根会直接**替换**，旧的那根掉落在陷阱方块的位置，不会消失。

空手右键点击陷阱可以把里面的末地烛**取出来**，直接放进主手。

## 伪装

主手拿任意**完整立方体方块**右键点击陷阱，陷阱会变成那个方块的样子（类似机械动力的伪装方块）。
只接受碰撞箱为完整立方体的方块，台阶、楼梯、栅栏、火把这类都不行；陷阱自己也不能伪装成自己。
伪装会消耗一个方块（创造模式同样消耗，和装填一样按容器处理），再次用别的方块右键就是换成新的伪装。

潜行 + 空手右键可以**取下伪装**，伪装用的方块还回主手，里面的末地烛不受影响。
不想叠方块时可以直接右键伪装；潜行右键则会把手上的方块交还给原版，可以正常往陷阱上面放方块。

伪装状态保存在方块实体里，随方块一起同步给客户端；客户端渲染器会按重映射后的方块模型绘制，
`mimicked=true` 时本体模型隐藏，避免和伪装重叠。

## 触发

装着末地烛的陷阱被**玩家踩到它的顶面**时触发（原版 `Block#stepOn` 语义：脚真的站在这个方块上，
从上方飞过、或者站在它上面那一格方块上都不算）。玩家潜行时同样会触发。

触发时按下面的顺序把末地烛塞进玩家**副手**：

1. 副手是空的 → 末地烛直接放进副手；
2. 副手有东西，主背包（36 格，不含盔甲和副手）有空位 → 先把副手物品放进那个空位，再把末地烛放进副手；
3. 副手有东西、背包也满了 → 把当前副手物品丢在玩家脚下，再把末地烛放进副手。

**一次触发只给一根**：陷阱只会存一根末地烛（装填和读档都会被压成单根），
同一陷阱两次触发之间至少间隔 20 tick（1 秒），所以站在上面或者边站边补装都不会一次刷出好几根。

触发后陷阱里的末地烛被清空，伪装保留，可以重新装填。只有玩家会触发，其它生物踩上去没有反应。
触发不再显示任何屏幕小字提示，只有发射器音效。

## 掉落

挖掉陷阱时（带正确的工具、非创造模式）分别掉落三样东西：

- 陷阱方块本身；
- 里面装着的末地烛（保留组件）；
- 伪装用的方块。

爆炸等其它破坏途径只走空掉落表，不会掉落内容物。

## 实现

- `EndRodTrapBlock`：右键交互、`stepOn` 触发、`playerDestroy` 掉落。
- `EndRodTrapBlockEntity`：保存末地烛 `ItemStack` 与伪装 `BlockState`，用 `TagValueOutput/Input` 读写，
  并通过 `getUpdatePacket` / `getUpdateTag` 同步到客户端。
- `EndRodTrapRenderer`：26.x 的渲染管线没有 `renderSingleBlock`，这里用 `BlockModelResolver` 把伪装方块
  的模型解析进 `BlockModelRenderState` 再提交。陷阱本体是实心方块，自身位置的亮度恒为 0，
  所以照明取六个邻居里最亮的天空光／方块光（并叠加伪装方块自身的发光），否则伪装会渲染成全黑。
