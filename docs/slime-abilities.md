# 驯服史莱姆：能力吸收、玩家囚禁与分解模式

## 获取与使用

- Lv.3 起可以吞入生物。只有分解成功、猎物正常死亡后才获得能力；吞入、释放、中途死亡或取消不会授予能力。
- 当前能力只有一个。苦力怕、末影人、潜影贝分别授予爆裂胶体、瞬移狩猎、漂浮冲击；新能力覆盖旧能力，普通生物不清空能力。
- 能力、冷却、蓄力和分解步骤随存档保存。重新加载不会重新支付正在分解实体的血量代价。
- Lv.3–4 时主人空手右键主动钻入后可驾驶。G 吞噬、V 发动当前能力、B 打开背包、潜行退出；按键可修改。
- 无人驾驶时由 AI 使用当前能力；Lv.5 以下待命模式不自动发动。瞬移寻找当前猎物及安全落点，成功后播放完整吞噬动画。
- 苦力怕能力有点火声、加速闪烁、膨胀、爆炸粒子、冲击环及胶体回弹。爆炸后史莱姆存活并进入冷却。
- 爆炸保护史莱姆、体内乘客和驯服宠物的伤害及击退，Lv.5 以下还保护体外主人；默认不破坏方块。开启方块破坏后遵守 mobGriefing。
- 潜影贝能力先抬升附近猎物，再集中到史莱姆头顶，最后落下并经过膨胀动画吞入。聚拢期间史莱姆停住，避免头顶位置持续移动；猎物保留方块碰撞，释放时恢复原来的 AI 和重力状态。配有潜影贝音效和末地烛粒子环。
- 苦力怕头、末影珍珠（伴随紫色粒子）、潜影壳作为体内能力核心，获得能力时短暂放大；核心不占物品槽。

## 囚禁与驾驶

- 玩家被吞时进入囚禁状态，包括在“吞人”指令下被动吞入的主人。囚犯不能驾驶、发动技能、使用物品攻击、挖掘或管理史莱姆背包。
- 玩家可自由转动视角观察史莱姆行动，并随其移动。连按 R 挣扎，Lv.5 以下还可以等待自动挣脱；潜行不能直接退出囚禁。
- Lv.5 以下主动钻入的主人单独记录为驾驶员，免疫挣扎，可以潜行退出；被动吞入不会自动升级成驾驶员。
- Lv.5 以下默认开启玩家囚禁时，体内玩家不进入分解队列。关闭后恢复玩家分解，但自动模式仍不会消化主动驾驶的主人。Lv.5 始终使用下面的延迟、缓慢玩家消化规则。
- Lv.5 以下自动吞入玩家仅在明确选择“吞人”且囚禁开关开启时允许；创造、旁观玩家不会成为自动/技能猎物。
- 被吞生物暂时禁用 AI，释放时恢复原来的 AI 状态。死亡、挣脱和释放都清理空间与分解目标。

## Lv.5 失控

- 到达 Lv.5 时撤销已有驾驶员身份，主人同样成为囚犯。史莱姆不再接受驾驶、待命、召回、背包管理和手动技能指令。
- 自主寻找猎物，主动发动变大吞噬，吞噬与吸收能力的冷却最多 200 tick（10 秒）。主人、其他生存／冒险玩家都会成为目标；创造、旁观玩家仍排除。
- 玩家被吞后默认有 3600 tick（3 分钟）保护期。不能潜行离开，必须连按 R 积累挣扎才能逃出；不操作不会自动退出。挣脱后有 5 秒重新捕获保护，留出跑开的时间。保护期内不会受到消化伤害。
- 玩家在体内呈舒展四肢的漂浮姿态，带轻微上下浮动。方向键（默认 WASD）水平飘动，跳跃键上浮，潜行键下沉；位置限制在体壁以内，每位囚犯独立移动。输入只移动体内位置，不能操控史莱姆；相对位置随存档保存，并同步给附近玩家。
- 保护期结束后每 100 tick（5 秒）受到 1 点伤害（半颗心）；自然回血暂停，治疗效果仍可用。不会进入普通生物 4 秒分解的队列。
- 世界画面随消化逐渐模糊，默认经过 1200 tick（1 分钟）达到最大模糊，HUD 显示剩余保护时间和挣扎进度。逃脱或死亡后模糊解除，不改写玩家画质设置。
- 囚禁计时随存档保存，只累计实体加载时的游戏 tick；重进世界不会重新获得完整保护期。生物在 Lv.5 自动分解，不需要主人投入催化剂。

## 分解模式

史莱姆背包右侧可以切换“自动消化 / 催化消化”，并用“喂催化剂”按钮消耗主手的一份分解催化物。

- 自动：吞入生物后直接逐个分解；普通收纳物品保留，只有投入催化剂才分解物品。
- 催化：等待催化剂，一份启动现有批次数量；批次未完成不能重复投入。
- 正在进行的步骤会完成，之后根据新模式继续。已支付的催化批次仍会处理其剩余任务。
- 每步沿用 80 tick（4 秒）及原有分解血量代价；血量不足挂起。正在分解的实体直到结算才归还空间。
- 正在消化的生物随进度逐渐缩小，结束前接近原尺寸的 10%；等待中的生物不提前缩小。玩家也会在保护期结束后随缓慢消化进度缩小，进度时长按消化开始时的生命、吸收生命和伤害间隔计算。原版尺寸属性同步模型、碰撞箱与第一人称视角；释放、挣脱或强制下车后移除消化缩放，保留原有尺寸设置。空间仍按吞入时的体积保留至死亡或释放。
- 消化死亡产生的正常掉落物自动进入史莱姆背包；实体释放的空间可立即用于这些掉落物，容量不足的部分保留在地上。只收取此次消化产生的掉落，不吸走周围已有物品；原版掉落规则（包括死亡保留物品）仍有效。
- 此次消化产生的经验直接吸收并保存为史莱姆的经验余额，避免经验球与附近旧经验球合并后误吸。余额显示在体内 HUD 和背包实体页，史莱姆死亡或被移除时掉回经验球，区块卸载不会释放。
- 囚犯不会挡住后面的可分解猎物，也不会让仅装有囚犯的史莱姆空耗催化剂。

## 配置

服务端 `config/justarod.json` 使用扁平键；新增键在启动时补全，已有配置屏幕会自动列出这些设置。多人游戏以服务端为准，玩家本地配置不能改写服务器规则。

| 键 | 默认值 | 含义 |
|---|---:|---|
| `slime.direct_digestion` | false | 新史莱姆的默认模式；每只可在背包界面覆盖 |
| `slime.player_captivity` | true | Lv.5 以下被吞玩家只囚禁、不分解 |
| `slime.abilities.enabled` | true | 能力吸收与发动 |
| `slime.abilities.explosion_power` | 5.0 | 爆炸强度，限制 0.5–12 |
| `slime.abilities.explosion_break_blocks` | false | 爆炸方块破坏 |
| `slime.abilities.creeper_fuse_ticks` | 40 | 蓄力时长，限制 10–200 tick |
| `slime.abilities.cooldown_ticks` | 600 | Lv.5 以下能力冷却，至少 20 tick；Lv.5 最多 200 tick |
| `slime.abilities.teleport_range` | 16.0 | 瞬移狩猎范围，限制 4–64 格 |
| `slime.abilities.levitation_radius` | 6.0 | 漂浮范围（史莱姆碰撞箱外扩），限制 1–16 格 |
| `slime.abilities.levitation_ticks` | 100 | 抬升、聚拢时长，随后落下吞噬；限制 20–400 tick |
| `slime.level5.player_grace_ticks` | 3600 | 玩家消化前的保护期，限制 20–24000 tick |
| `slime.level5.player_damage_interval` | 100 | 缓慢消化伤害间隔，限制 20–1200 tick |
| `slime.level5.player_damage` | 1.0 | 每次消化伤害，限制 0.5–4 点 |
| `slime.level5.player_blur_ramp_ticks` | 1200 | 模糊达到最大强度的时长，限制 20–24000 tick |

## 验证与镜头

运行 `./gradlew :common:verifyMixins :fabric:runGameTest :fabric:shadowJar :neoforge:shadowJar`。
GameTest 使用 `fabric/build/run/gameTest` 下的独立世界，报告写入 `fabric/build/slime-gametest.xml`；测试代码不会进入发布 jar。
本地 toNeko 前置仍有旧版依赖名、Mixin 目标／存档签名及方块注册错误，无法直接启动 26.1.2。测试任务在 `fabric/build/gametest-fixtures` 生成隔离副本：保留接口实现，禁用该前置的入口、注入和数据包，并在独立测试世界把旧 `fabric` 依赖名覆盖为 `fabric-api`。原始前置 jar、发布 jar 和用户存档都不受改动。因此这组测试验证 JustARod 的史莱姆功能，不证明原 toNeko 的兼容性；正常游戏仍需换用兼容 26.1.2 的前置。

原有 8 项服务端集成测试覆盖：消化完成才授予能力并保留收纳物品；释放取消且恢复 AI；保存／加载恢复进度且不重复扣血；催化模式等待投入；被动吞入主人保持囚禁且可挣脱；爆炸保护驾驶者并保留能力；安全瞬移后吞噬；漂浮实际抬升猎物。测试环境自带的 `minecraft:always_pass` 不计入这 8 项。

移动回归另有 5 项：带有旧移动指令／水平速度时主动进入即停止；驾驶中松开方向键立即停止水平移动；囚禁主人且无猎物时不持续移动；囚禁乘客仍允许 AI 靠近并吞噬真实猎物；正常跟随主人仍可移动。测试启用真实 AI，避免仅用 NoAI 实体遗漏移动控制器的问题。

客户端骑乘不授予史莱姆本地移动模拟权限，服务器以真实玩家输入处理驾驶，客户端插值接收位置。无驾驶输入或无 AI 行动请求时会清除水平惯性和移动控制器指令，竖直速度保留以正常落地。跟随、追击、吞入和浮水目标每 tick 明确请求动作，体内有囚犯不会使史莱姆永久停住。

Lv.5 与潜影贝的 4 项服务端测试覆盖：Lv.5 升级撤销驾驶权；忽略待命并主动吞入主人和其他玩家、10 秒冷却；保护期后缓慢扣血、读档计时与挣扎逃脱；潜影贝头顶聚拢后掉落吞噬并恢复猎物状态。

缩小、漂浮与掉落的 4 项服务端测试覆盖：仅当前猎物缩小、释放恢复原尺寸且不提前归还空间；独立体内移动、碰撞箱边界、视角缩小和相对位置存档；正常生物掉落与经验吸收且不取走已有掉落；玩家缓慢消化死亡后的背包掉落、经验及容量溢出保留。共 21 项功能测试，另有原版 `always_pass`。

真实客户端回归可用 `./gradlew -PslimeClientTests :fabric:runClientGameTest` 单独运行。它通过正常网络连接检查本地骑乘权限、无按键静止、真实 WASD 驾驶及松键停止、囚禁主人时无猎物保持静止、Lv.5 体内移动同步与非坐姿模型、潜行下沉且无法退出、同步保护期、玩家缩小后的视角、实际模糊半径、真实 R 按键逃脱及尺寸复原、普通生物模型缩小和消化奖励同步，并保存截图至客户端测试目录。

建议用 Lv.4 手动拍摄：主人占 16 格，末影人占 24 格，而 Lv.3 内部只有 27 格，驾驶时放不下末影人。Lv.5 的技能由 AI 发动，适合拍摄失控与囚禁镜头。先开启自动消化并吞入苦力怕，获得体内头颅后主动驾驶，按 V 拍摄蓄力与爆炸。切换能力则依次消化末影人、潜影贝。
画面仍需在客户端确认：透明排序、第一人称囚禁视野、闪烁频率、膨胀与回弹、粒子密度及不同 GUI 缩放下的按钮位置。
